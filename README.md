# 投資運用（Claude連携・auカブコム証券 自動売買）

Claudeによる市場分析・売買判断と、auカブコム証券「kabuステーションAPI」を使った
自動発注を組み合わせた投資運用ツールです。**実際のお金を動かす仕組みなので、
必ず内容を理解した上でDRY_RUNのまま十分に検証してから実運用してください。**

## 構成

| ファイル | 役割 |
|---|---|
| `kabu_client.py` | kabuステーションAPIのクライアント（価格取得・発注・ポジション取得など） |
| `claude_analyzer.py` | Claude APIに価格情報を渡し、BUY/SELL/HOLDを判断させる |
| `risk_manager.py` | 固定注文サイズ・1日の最大損失額を管理し、上限に達したら自動停止する |
| `trading_bot.py` | 上記を組み合わせて「分析→判断→発注」を1サイクル実行するスクリプト |
| `app.py` | 取引ログ・本日の損益状況を表示するStreamlitダッシュボード（発注はしない） |

## 重要な前提：kabuステーションAPIはローカルAPI

kabuステーションAPIは、Windows専用アプリ「kabuステーション」が起動している
PC上でのみ動作するローカルREST APIです。クラウド（Databricks Appsなど）から
直接呼び出すことはできません。

そのため：

- **`trading_bot.py`（実際の発注を行う部分）は、kabuステーションが起動している
  自分のPC上で実行する**必要があります。
- `app.py`（ダッシュボード）は、`trading_bot.py`と同じディレクトリ・同じマシンで
  実行すれば、生成された`trade_log.csv`と`risk_state.json`を読み込んで状況を
  表示します。クラウドで見たい場合は、別途ファイルを同期する仕組みが必要です
  （今回のスコープには含まれていません）。

## セットアップ

1. auカブコム証券の口座を開設し、kabuステーションAPIの利用登録を行う
   （公式サイトの案内に従ってください）。
2. kabuステーションを起動し、APIを有効化する。
3. 依存パッケージをインストール:
   ```
   pip install -r requirements.txt
   ```
4. `.env.example` を `.env` にコピーし、各値を自分の環境に合わせて設定する:
   ```
   cp .env.example .env
   ```
   - `KABU_API_PASSWORD` / `KABU_ORDER_PASSWORD`: kabuステーションで設定したパスワード
   - `ANTHROPIC_API_KEY`: Claude APIキー
   - `SYMBOLS`: 対象にしたい証券コード（例: `7203,9984`）
   - `ORDER_SIZE_YEN` / `DAILY_MAX_LOSS_YEN`: 1回の注文予算と1日の損失上限
   - `DRY_RUN=true`（初期値のまま）

## 実行方法

### 1. まずはDRY_RUNで動作確認（発注は行われません）

```
python trading_bot.py
```

`trade_log.csv` に、Claudeがどう判断したか・実際に発注するとしたら何株になるか
がログとして出力されます。何度か実行し、判断内容・数量計算・エラー処理が
想定通りかを確認してください。

### 2. ダッシュボードで確認

```
streamlit run app.py
```

### 3. 実運用（実際の資金で発注）

十分に検証できたら `.env` の `DRY_RUN` を `false` にします。**この時点から
実際の口座で注文が発注されます。**

必要に応じて `cron` やタスクスケジューラで `trading_bot.py` を定期実行してください。

## リスク管理の仕組みと限界

- **固定注文サイズ**: `ORDER_SIZE_YEN` の予算内で、単元株数の倍数になるよう
  注文数量を計算します（予算が単元株1つ分に届かない場合は発注を見送ります）。
  日本株は基本100株単位（単元株）なので、「株価 × 100」を下回る予算の銘柄は
  常に見送られます（例: 株価3,000円の銘柄には最低300,000円が必要）。
  「小額」で始めたい場合は、株価の低い銘柄を選ぶか、単元未満株（ミニ株・
  S株など）に対応した別のサービス・APIを検討してください（kabuステーション
  APIの標準発注は単元株単位が前提です）。
- **1日の最大損失額**: `risk_state.json` に当日の損益を記録し、
  `DAILY_MAX_LOSS_YEN` を超えて損失が出た場合、新規注文を停止します。
  - 保有ポジションの損益（`ProfitLoss`フィールドを想定）を毎回取得して反映します。
    ただし、このフィールド名は口座種別やAPI仕様により異なる場合があるため、
    自分の環境でのレスポンスを確認し、`trading_bot.py`の`_sum_unrealized_pnl`を
    必要に応じて調整してください。
- 日付が変わると損益・発注件数はリセットされます。

## 免責事項

- 本ツールはClaudeによる自動判断で実際の注文を送信します。判断や実装に誤りが
  あれば損失につながる可能性があります。
- `kabu_client.py`内の発注パラメータ（`FundType`など）は、口座設定やAPI仕様の
  変更によって正しく動作しない場合があります。**本番発注の前に、必ず
  kabuステーションAPIの公式仕様書と自分の口座設定を確認してください。**
- 自動売買の利用は自己責任で行ってください。
